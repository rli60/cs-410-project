# Movie Recommender System

This movie recommender system lets people describe what they want to watch in plain language, such as "an action movie with a big plot twist" or "a funny family movie that is short." Instead of scrolling through broad genres or relying on past ratings, users get ranked results that match what they actually asked for.

## Data

We use the [MovieLens dataset](https://grouplens.org/datasets/movielens/), which includes movie genres, user-generated tags, and tag relevance scores. As a stretch goal, we may add movie information from other sources.

## Tech Stack

- **Backend:** Python
- **Frontend:** React
- **Retrieval:** TF-IDF and BM25
